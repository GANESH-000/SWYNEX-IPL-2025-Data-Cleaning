# SWYNEX – IPL 2025 Data Cleaning & Preparation

## Objective
Clean and prepare a simple IPL 2025 match dataset for analysis using Microsoft Excel.

## Dataset Columns
- Match ID
- Date
- Venue
- Team 1
- Team 2
- Result

## Data-quality issues identified
- Duplicate records
- Extra spaces
- Inconsistent capitalization of team names
- Inconsistent date formats
- Missing values
- Match ID formatting issues

## Cleaning steps
1. Checked the dataset for missing values.
2. Checked for duplicate records and removed duplicates.
3. Removed extra spaces from text columns.
4. Standardized team names.
5. Standardized dates to DD-MM-YYYY.
6. Converted Match ID to an integer field.
7. Checked venue and result values for consistency.
8. Saved the cleaned dataset as an Excel file.

## Files
- `IPL_2025_RAW_Data.csv` – original raw dataset.
- `IPL_2025_Cleaned_Data.xlsx` – cleaned dataset.
- `README.md` – project documentation.

## Tools
Microsoft Excel and CSV

## Result
The cleaned dataset is standardized and ready for further analysis or visualization.
